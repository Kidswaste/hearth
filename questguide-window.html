Start a guided quest in Sidequest Studio.

Connect FL Studio

Easiest: watch your saved project. Choose this quest’s .flp once. Set your tempo or add piano-roll bass notes, then press Ctrl+S in FL Studio. Hearth reads that file and checks your step. No MIDI device needed.

Or connect live

Install Hearth’s read-only controller script, then enable Hearth Quest Guide for an unused MIDI input in FL Studio’s MIDI settings.

  1. Install the script below.
  2. Open FL Studio → Options → MIDI settings. Refresh the device list if needed.
  3. Select an unused input and enable it. Choose Hearth Quest Guide (user) as its controller type.
  4. Wait for the “Connected” light here.

Needs a MIDI input, physical or virtual. Keep your usual keyboard controller on its own script. No available input? Use the saved-project option above. The script observes tempo, playback and bass-channel notes/activity; it never changes your project.
