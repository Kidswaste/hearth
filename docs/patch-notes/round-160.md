# Round 160: a lighter start, part 2
*November 2026*

## Faster to open

Hearth now reads about a tenth less code before its window shows up (1,168 KB → 1,039 KB). On our slow test computer
the first screen is up in 482 ms instead of 512 ms (median of 10 starts).

## Nothing else changes

The keys sheet, the right-click menus, the look picker and a few other things you open on purpose arrive a moment after
the window does; they list exactly the same lines in the same order as before.
