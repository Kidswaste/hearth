# Round 186: Forge Debug stops asking, and folded replies open where you look
*November 2026*

## ⚒ No more permission cards in Forgeheart
- **Forge Debug now works without asking.** It pushes to GitHub, deletes, installs software and uses the network by
  itself. The next time Hearth starts, a note says so.
- Everything it does is still written in its activity log, and a plain delete still goes to the Trash.
- **The few things it still asks before**: reading a file that holds keys or passwords, changing the system
  (shutting down, stopping programs), deleting or writing outside its folders, and a command Hearth can't read.
  Anything that needs a password is still refused: Hearth never types passwords.
- To turn it off: ⋯ AI setup › Files on this computer › **Work without asking**. Turned off, Hearth does not turn it
  back on. The same switch is there for any Claude AI set to Full.

## 💬 Long replies with pictures
- A long reply is folded so the chat stays short. Its **Show full reply** button sat at the very end of the reply,
  below its pictures: with a big picture the text looked cut off with no way to read the rest.
- The button is now a wide one **right under the faded text**, above the pictures.
- **Clicking the faded text opens the reply too.**
