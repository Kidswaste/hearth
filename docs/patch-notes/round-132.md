# Round 132: explain a layer, scene versions, and cheaper messages
*November 2026*

## ✦ Explain this layer
- Right-click a layer (or the Sliders panel's ⋯) › **✦ Explain this layer**. A small card above the sliders shows the
  cost first; one click and the AI says in plain words what the layer draws and how it moves, which sliders matter
  most, and what each part of its code does. It's remembered: opening it again is free until the code changes.
- **Make it…**: type what you want ("slower and blurrier on the breaks"). If the sliders can do it, it's done at once
  (one Undo); if not, it goes to the director as your message.
- **+ Turn into a slider**: a fixed number in the code (say 12 spheres) becomes a slider in one click (one Undo).

## 🕘 Scene versions
- Sketch ▾ › History › **🕘 Scene versions…** (or **Save a version…** to name one). Hearth also keeps a version on its
  own before each AI change, before a first draft and when you keep a take. Each row shows a picture, the name, when
  and who (you, Claude or Astra).
- Tick 2 to 4 (or "Now") and **Compare**: they play side by side, live with the song, each with one line on what
  changed. **Use this one** brings a version back, **Take only…** brings back a single layer; each is one Undo.
- Deleted versions go to the Lab's Trash for 30 days. Versions you named are never thinned out.

## 💬 Cheaper messages to the Lab's AI
- Every message to the Three Director costs about 16 % less (the full tool list's details now come on demand), and
  the lean director about 100 tokens less, with nothing it can do taken away.
