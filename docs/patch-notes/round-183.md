# Round 183: the chat is back in the Forgeheart window
*November 2026*

## ⚒ The chat, beside the game
- **Open Forgeheart and the Forge chat is on the right again.** It is your Forge Debug chat, with all its earlier
  conversations. The 💬 button at the top right shows or hides it.
- **▶ Live game** is a new first tab: the game the chat can drive, with its toolbar (pause, speed, God, spawn,
  patches). Ask for "20 drones", "stage 80" or "god mode" and it happens there.
- **Ask while the game isn't open and it opens by itself**, then the chat waits for it to load.
- Forge Debug is no longer a separate chat in the Chats bar: it lives in the Forgeheart window.

## 🧠 It knows what Forgeheart is
- **With every message it gets your brief** (Dashboard › the brief; edit it any time), where the project lives, and
  the names of your design notes.
- **It can read your design notes by itself**: list them, open one, or search all of them for a word. It is told to
  read them before answering a question about the game's design or history, instead of guessing.
- **✦ Digest my notes** (Dashboard › What the chat knows): one click and the AI reads your design notes once, then
  writes a short digest of the game (what it is, its systems with your names and numbers, where it stands). The chat
  carries it with every message from then on. You can read and edit it. It is one larger AI call, only when you
  click; do it again after big changes.
- **It sees what the game is doing.** Every message you send carries one hidden line: the stage, gold, HP, how many
  enemies and which kinds, the boss, god mode / pause / speed, and which tab or note you are looking at. So "why is
  this so hard?" gets an answer about what is on screen.
- "Ask Claude about this" on a doc, a task or the balance table now goes to this chat.

## Good to know
- Tried in a throwaway copy of Hearth with your real build and notes: the game loaded and took commands, and all 34
  notes were listed, read and searched. No real conversation was run, so how well it answers is for you to judge.
  Try: "what are rifts for?" and "spawn 20 drones".
- Three new buttons under the chat: 📊 Status, 📸 Look at it, 📚 My notes.
- If you have no Forge chat at all, the "💬 Forgeheart chat" button in the window makes one.
