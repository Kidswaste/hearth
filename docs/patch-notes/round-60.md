# Round 60: a solid Windows install
*October 2026*

## 🪟 Hearth on Windows updates cleanly
- A fresh install from the Windows zip now updates without false "50 new changes" counts or a wrong merge, even though it starts with a short history.
- If GitHub refuses (the code is private), ⬆ Update says **Sign in to GitHub** with one button: it opens GitHub's own sign-in window once and remembers it. Without Git, **Install Git** installs it and signs you in right after.
- On its first start Hearth now puts a **Hearth** shortcut in the Start menu and on the Desktop (shortcuts to an older copy are left alone, and you're told how to point them here).
- "Start with Windows" works from a folder with spaces in its name.

## ▶ Play offline
- Without internet and without a saved copy of three.js, ▶ Play says so in one plain line (and works offline once it has downloaded it once), instead of a long technical error.

## Behind the scenes
- Tests that need real hardware or a live account only run when asked.
