# Round 31: cheaper messages, smooth Lab, perfect loops, file access fixed
*October 2026*

## 📂 File access works the way it looks
"Full" in ⋯ AI setup now applies to every chat of that AI, new ones included (it used to change only the open chat).
**Find it:** ⋯ AI setup › What it can use › Files on this computer.
- Pick the folders it may use: ＋ Add a folder…, or My home folder (with a warning).
- When something is refused, the chat says why in one line, with Allow this folder / Allow edits / Allow commands.
- One chat can still differ: right-click ⋯ › Access › "As in AI setup" or its own level.

## 🪙 Fewer tokens on every message
- A plain Claude chat sends 34% less with each message (869 → 572); AIs with board / screenshot / app tools 20–30% less.
- Tool details are fetched only when needed; big memories send only what's relevant.

## 🎛 The Lab stays smooth on any machine
The preview lightens itself in steps when frames drop (resolution, filters, shadows, particles) and comes back up when it can.
**Find it:** by itself; right-click the preview › View › Lighten to stay smooth to switch it off.
- Layers hidden under an opaque one stop drawing.
- Renders, stills and freezes are always full quality.

## ∞ Perfect loops
**Find it:** ✦ More › Make › Make it loop; the Lab mission; Ready to post's loop fix; or ask the Lab's AI.
- Time, keyframes and music reactions wrap over N bars; scenes that can't loop get a cross-fade.
- A check says "≈ seamless" or "a visible jump", with a one-click fix; renders a perfect-loop video.

## ✦ What can I do here?
One calm card per window with 3–5 things to try, picked from what you haven't used yet and what's open.
**Find it:** shows once per window; then "?" in AI setup, the Lab's ⋯, the board's ⋯, Ctrl/⌘+K.

## 🍎🪟 Mac + Windows
- File names with #, ?, % or accents load everywhere; Windows paths no longer mix slashes.
- Mac: tools installed with Homebrew / npm are found when Hearth starts from the Dock; the Dock icon brings back a hidden window; shortcuts show ⌘.
- Windows: click "Create Start menu & desktop shortcuts" once so notifications work.

- On Windows, Claude installed through npm (claude.cmd) still isn't found by itself.
