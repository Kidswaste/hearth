# Round 26: simpler chats, missions, more reach for the AIs
*October 2026*

## ⋯ AI setup replaces commands
Typing "/" no longer opens a command menu. Everything is a click away instead.
**Find it:** ⋯ in a chat's header, ⋯ on a window's header, ❖ in the rail.
- **Personality**, **Instructions** (rules it always follows, each one on/off), **Memory**, **Habits**, **How hard it thinks**.
- Saved on the AI itself: nothing is tucked into your message any more.

## ◎ Missions
Pick what your next message becomes.
**Find it:** ◎ next to Send.
- Split it up, Swarm, Answer then review, Debate, Side by side, Jam, Pair on code, Ask everyone; under More: Plan first, Research, Teacher, Second opinion only.
- One click = next message only; 📌 = from now on; right-click ◎ = back to normal.
- Multi-AI missions end in one calm card: who took part, live status, the answer first, Use this one / Merge.

## ⚡ Hooks
"When something happens, this AI does this."
**Find it:** ⋯ AI setup › Hooks.
- A render finishes, a Lab error, a file lands in a folder, a time of day, an update, another AI replied, the board got something new.
- At most once a minute, waits while the AI is answering, never loops.

## 🔌 Connections
Give an AI more reach (MCP servers).
**Find it:** ⋯ AI setup › What it can use › ＋ Add a connection.
- 8 ready-made (folder files, web pages, git, database, browser…) or your own; Off / Read only / Full per AI; a Test button.

## The Lab without commands
**Find it:** right-click the picture › ✦ More; toolbar ⋯ › Director; right-click a layer.
- Lab missions: 4 variations, react to the music, 9:16 version, polish the look, render it.

## Sync conflicts settle themselves
Data merges, files keep the newer one; the other version waits in Deleted files for 30 days.
**Find it:** the conflicts window: ✓ Settle all for me, ↻ Refresh.

## Good to know
- Hooks watching a folder were tested on Linux only so far.
- Connections set to Full are pre-approved for that AI, like Hearth's own tools.
