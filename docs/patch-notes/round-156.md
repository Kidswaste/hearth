# Round 156: A lighter, quicker start
*November 2026*

## Faster to open

Hearth now reads about a quarter less code before it shows your chats (1,547 KB → 1,172 KB). On the test computer the
first screen is up in 0.47 s instead of 0.52 s. Astra, file access, the offline helper and the extras under each reply
now load a split second after the first picture, so nothing you use changes.

## It stays that way

The start now has a lower size limit, so new features can't quietly make it slow again.
