# Round 179: filters in new-format scenes, and fast layers from more places
*November 2026*

## Filters on the new engine

- **Filters now work in a new-format scene without slowing it down.** Add one from ＋ Layer › Filters, the FX picker,
  a look or Blocks, or ask Claude or Astra: it runs on the scene's one renderer, with the same sliders and the same
  reactions to the music. Before, a filter in a new scene was the old heavy kind and most likely did not even see the
  fast layers under it.
- **121 of the 124 filters** work this way. They look the same as before: the ones compared side by side with the old
  engine matched.
- The layer's opacity mixes the filter with the original, as always. A filter turned down to 0 costs nothing.
- **Not yet**: Crystal, Oil paint and ◐ Grade are still the old kind in a new scene. The REC overlay of the VHS filter
  is missing there.

## Fast layers from more places

- **Code from a chat.** When Claude or Astra writes a fast (new-format) layer in a reply, it now has the
  "▶ Apply to scene" button, and "Open in the Lab" makes a new-format scene from it. Before, that code opened as an
  old scene and showed nothing.
- **Dropping a picture or a clip** onto a new-format scene makes a fast layer, with the same Fit, Zoom and drift
  sliders.
- **New projects**: Audio visualizer, Particles and Footage + effects now start with fast layers.

## Still the old kind, for now

- Grade, shader layers, type, physics, the motion kit, 3D models, the gallery's starting points, Describe it and
  Blocks. Shader art, Kinetic type and the 3D model showcase projects still start as old-format scenes.
