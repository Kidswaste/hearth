# Round 179: more of what you add to a new scene is the fast kind
*November 2026*

## Fast layers from more places

- **Code from a chat.** When Claude or Astra writes a fast (new-format) layer in a reply, it now has the
  "▶ Apply to scene" button, and "Open in the Lab" makes a new-format scene from it. Before, that code opened as an
  old scene and showed nothing.
- **Dropping a picture or a clip** onto a new-format scene makes a fast layer, with the same Fit, Zoom and drift
  sliders.
- **New projects**: Audio visualizer, Particles and Footage + effects now start with fast layers.

## Not yet

- Filters, Grade, shader layers, type, physics, the motion kit, 3D models, the gallery's starting points, Describe it
  and Blocks still make old-format layers. The new engine first needs a way for a layer to restyle the picture under
  it, and a way to run the existing shaders; that is the next piece of work.
- Shader art, Kinetic type and the 3D model showcase projects still start as old-format scenes for the same reason.
