# Round 171: long chats scroll without hitches
*November 2026*

## Scrolling long chats

- **Scrolling up through a long chat no longer stutters while older messages load in**: each piece now costs about
  half the work it did. Your first scroll, click or key after a short pause no longer redraws the whole window either.

## Switching between the Lab and a chat

- **Going from the Lab to a chat (and back) does about half the drawing work it did.** Nothing looks different.
