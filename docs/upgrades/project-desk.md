# Project desk and editable identities

Projects now open to their live chat with a compact resource shelf. The shelf links to the project's moodboards, drawing/storyboard, recent assets, instruments and searchable scene modules. Setup, notes and long AI descriptions are folded away. The top tabs remain the primary navigation.

The logo editor can generate lettering, a composition and named animated shapes with AI. Edit fonts, finish, spacing, depth, colours, layout, position, scale and rotation; select shapes in the preview or list; add, duplicate, remove, undo and redo. One worker and WebGL context are reused while editing. Idle project cards show saved posters and animate only on hover.

Reusing a chat composer no longer adds collaboration buttons or listeners. Closing a project without a song no longer launches the media picker. The 60 fps limiter carries fractional deadlines on 75/100/144/165 Hz displays rather than falling to a lower fixed fraction.

Validation: project desk and project-fluidity Electron journeys; frame pacing, projects and workspace tests; boot checks. The optional guarded Clinky paper upgrade reuses vector dot geometry and is applied through scene history, never by replacing the scene database. Full-resolution gameplay still depends on scene drawing cost and hardware; this update does not guarantee 60 fps or silently lower resolution. macOS uses the same browser APIs; no physical Mac test was performed.
